# Singkil Project

An Indonesian-language landing page for Singkil Project, presenting its software development and IT services, technology stack, collaboration options, and contact links.

## View the page

Open `home.html` in a web browser. The page is a standalone HTML file and does not require a build step. Tailwind CSS, Font Awesome, and the Inter font are loaded from external CDNs, so an internet connection is needed for those assets.

## Project files

- `home.html` - the landing page and its responsive navigation.
